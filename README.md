# hsr-VideoVersionKey-extractor
A tool to get the "VideoVersionKey" from a certain turn-based game

Created based on [reliquary-archiver](https://github.com/IceDynamix/reliquary-archiver)


### build example

```
cargo build --release --no-default-features --features pktmon
```

## run

1. launch the game
2. run the compiled exe file with administrator privileges
3. start the game
4. if successful, a json file will be output
